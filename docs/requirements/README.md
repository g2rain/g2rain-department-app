# 需求索引

每个部门或数据权限前端需求使用独立 Markdown 文件，例如 `YYYYMMDD-short-name.md`。

```markdown
# 需求标题

## 背景与目标

## 范围与非目标

## 用户、部门与权限场景

## 业务规则和后端契约

## 页面、路由与资源权限

## 独立/集成模式影响

## 安全与审计

## 验收条件

- [ ] 可观察结果

## 测试、发布与回滚
```

需求必须明确 `g2rain-department-app` 的交互责任和 `g2rain-department` 的权威规则。跨仓库改动列出契约与发布顺序，不默认扩大范围。
