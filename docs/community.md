# 社区协作

问题与需求提交到 g2rain [Issues](https://github.com/g2rain/g2rain/issues)，开放讨论使用 [Discussions](https://github.com/g2rain/g2rain/discussions)。安全问题按仓库 `SECURITY.md` 私下报告。

提交变更时说明影响的部门/数据权限领域、独立与集成模式、资源配置以及验证结果。跨 App 规则进入中央 `frontend-app` Profile，服务端业务规则进入 `g2rain-department`。
